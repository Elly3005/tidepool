# Changelog

All notable changes to Tidepool will be documented in this file.

## [0.1.0] - 2026-10-26

### Added

- Local-first AI workbench for OpenAI-compatible models
- Chat playground with configurable model endpoint and API key
- Reusable agent skill editor
- Lightweight evaluation harness for prompt behavior checks
- MIT license and GitHub project publishing setup

### Notes

- The project is intentionally simple and browser-first for local experimentation
- No remote backend is required for the default flow
